Desde Qué probar

Taildrop: enviar archivos al servidor ("AirDrop" propio)

Qué es

Taildrop es la función de Tailscale para enviar archivos entre tus dispositivos. En el servidor, un servicio recoge automáticamente todo lo que llega y lo guarda en el HDD. Funciona en casa y fuera de casa, sin abrir puertos.

Celular / ASUS ──(Tailscale, cifrado)──► leandro-home-server ──► /srv/servidor/archivos/Taildrop
                                                                    = Z:\Taildrop en el ASUS

Cómo usarlo

Desde Pasos
Celular (Android) En cualquier app (Galería, Archivos, WhatsApp...): Compartir → Tailscale → leandro-home-server
ASUS (Windows) Clic derecho sobre un archivo → Enviar con Tailscale → leandro-home-server

Dónde aparece: | Desde | Ruta | |---|---| | ASUS | Z:\Taildrop (pulsa F5 si no se ve aún) | | Celular (CX File Explorer) | archivos → Taildrop | | Servidor | /srv/servidor/archivos/Taildrop |

Si envías dos veces un archivo con el mismo nombre, no se sobrescribe: el nuevo se renombra (foto (1).jpg).

Cómo está configurado (2026-11-13)

sudo tailscale set --operator=leandro          # leandro puede usar 'tailscale file get' sin sudo
# servicio: /etc/systemd/system/taildrop-recibir.service (ver configuraciones/taildrop-recibir.service)
sudo systemctl daemon-reload && sudo systemctl enable --now taildrop-recibir
Opción Función
User=leandro Los archivos quedan como tuyos: se abren y borran desde Windows sin problemas
--loop Recoge cada archivo apenas llega
--conflict=rename Nunca sobrescribe
RequiresMountsFor=/srv/servidor Si el HDD no está montado, no recibe (protege la microSD)
Restart=always Se reinicia solo si falla

Fotos HEIC

  • Samsung guarda las fotos en HEIC si la opción "Fotos HEIF" de la cámara está activa. Windows no las abre sin extensión.
  • Solución aplicada: en el celular, Cámara → ⚙️ → Opciones avanzadas de imagen → Formatos de imagen → "Fotos HEIF" desactivado. Las fotos nuevas salen en JPG.
  • Las fotos antiguas de la galería siguen siendo HEIC. Opciones:
  • Windows: instalar "Extensiones de imagen HEIF" (gratis, Microsoft Store).
  • Servidor (conversores instalados: libheif-examples, webp). Conversión manual sin borrar los originales: bash cd /srv/servidor/archivos/Taildrop && for f in *.heic; do heif-dec -q 92 "$f" "${f%.heic}.jpg" >/dev/null && touch -r "$f" "${f%.heic}.jpg" && echo "OK $f"; done; cd ~
  • Si Windows dice "COM Surrogate tiene abierto el archivo" al borrar un HEIC: cambia la vista a Detalles, cierra el panel de vista previa (Alt+P) o finaliza COM Surrogate en el Administrador de tareas, y reintenta.

Si deja de recibir archivos

systemctl status taildrop-recibir --no-pager | head -6      # debe estar active (running)
journalctl -u taildrop-recibir -n 20 --no-pager
sudo tailscale file get --verbose /srv/servidor/archivos/Taildrop/   # recoger a mano lo pendiente
sudo chown -R leandro:leandro /srv/servidor/archivos/Taildrop
sudo systemctl restart taildrop-recibir
  • moved 0/0 files = no había nada pendiente (el servicio ya lo había recogido).
  • Comprueba que el celular tenga Tailscale Connected y que el servidor aparezca en la lista al compartir.

scripts/backup-servidor.sh
#!/bin/bash
# ============================================================
# LEANDRO HOME SERVER - Copia de seguridad diaria
# Ubicación: /usr/local/sbin/backup-servidor.sh (se ejecuta como root)
# Lo lanza: backup-servidor.timer (todos los días 03:15)
# ============================================================
set -uo pipefail
export LC_ALL=C

DESTINO=/srv/servidor/backups
LOG=/srv/servidor/registros/backup.log
NODERED=/home/leandro/.node-red
BD=/srv/servidor/bases_datos/domotica.db
GUARDAR_DIARIAS=7
GUARDAR_SEMANALES=4
GUARDAR_MENSUALES=6

HOY=$(date +%F)
DIR="$DESTINO/diario/$HOY"
FALLOS=0

log()  { echo "$(date '+%F %T') $*" | tee -a "$LOG"; }
paso() {
  local desc=$1; shift
  if "$@"; then log "  OK    $desc"; else log "  ERROR $desc"; FALLOS=$((FALLOS+1)); fi
}

# 0. Si el HDD no está montado, NO escribir en la microSD
if ! mountpoint -q /srv/servidor; then
  echo "HDD no montado en /srv/servidor: backup cancelado" >&2
  exit 1
fi

mkdir -p "$DIR" "$DESTINO/semanal" "$DESTINO/mensual"
log "=== Inicio backup $HOY ==="

# 1. Configuración del sistema (/etc completo)
paso "etc.tar.gz"      tar --warning=no-file-changed -czf "$DIR/etc.tar.gz" -C / etc
chmod 600 "$DIR/etc.tar.gz" 2>/dev/null

# 2. Node-RED (sin node_modules)
paso "nodered.tar.gz"  tar --exclude=node_modules -czf "$DIR/nodered.tar.gz" -C "$(dirname "$NODERED")" "$(basename "$NODERED")"

# 3. Base de datos (copia consistente)
paso "domotica.db"     sqlite3 "$BD" ".backup '$DIR/domotica.db'"
paso "domotica.db.gz"  gzip -f "$DIR/domotica.db"

# 4. Persistencia de Mosquitto
paso "mosquitto.db"    cp -p /var/lib/mosquitto/mosquitto.db "$DIR/mosquitto.db"

# 5. Scripts propios
paso "scripts.tar.gz"  tar -czf "$DIR/scripts.tar.gz" -C / usr/local/bin usr/local/sbin

# 6. Inventario de paquetes
paso "paquetes.txt"    sh -c "dpkg --get-selections > '$DIR/paquetes.txt'"
paso "congelados.txt"  sh -c "apt-mark showhold > '$DIR/paquetes-congelados.txt'"

# 7. Sumas de verificación
paso "SHA256SUMS"      sh -c "cd '$DIR' && sha256sum *.gz *.db *.txt > SHA256SUMS"

# 8. Semanal (domingo) y mensual (día 1)
if [ "$(date +%u)" = "7" ];  then paso "copia semanal" cp -a "$DIR" "$DESTINO/semanal/$HOY"; fi
if [ "$(date +%d)" = "01" ]; then paso "copia mensual" cp -a "$DIR" "$DESTINO/mensual/$HOY"; fi

# 9. Rotación: conservar solo las N copias más recientes
rotar() {
  local carpeta=$1 n=$2 d
  find "$carpeta" -mindepth 1 -maxdepth 1 -type d -name '20??-??-??' | sort | head -n -"$n" |
  while read -r d; do rm -rf -- "$d" && log "  Rotación: eliminada $d"; done
}
rotar "$DESTINO/diario"  "$GUARDAR_DIARIAS"
rotar "$DESTINO/semanal" "$GUARDAR_SEMANALES"
rotar "$DESTINO/mensual" "$GUARDAR_MENSUALES"

# 10. Permisos: leandro puede leer, solo root escribe
chown -R root:leandro "$DESTINO/diario" "$DESTINO/semanal" "$DESTINO/mensual"
find "$DESTINO/diario" "$DESTINO/semanal" "$DESTINO/mensual" -type d -exec chmod 750 {} +
find "$DESTINO/diario" "$DESTINO/semanal" "$DESTINO/mensual" -type f ! -name 'etc.tar.gz' -exec chmod 640 {} +

TAM=$(du -sh "$DIR" | cut -f1)
LIBRE=$(df -h --output=avail /srv/servidor | tail -1 | tr -d ' ')
if [ "$FALLOS" -eq 0 ]; then
  log "=== Backup OK: $DIR ($TAM) · libre en HDD: $LIBRE ==="
  exit 0
else
  log "=== Backup con $FALLOS ERROR(ES): revisar $LOG ==="
  exit 1
fi

#!/bin/bash
# LEANDRO HOME SERVER - Estado del servidor en JSON (solo lectura)
export LC_ALL=C   # punto decimal (no coma) aunque el sistema esté en español
# Ubicación: /usr/local/bin/estado-servidor.sh   · Lo usa Node-RED (nodo exec)

# CPU: dos muestras de /proc/stat separadas 1 s
read -r _ u1 n1 s1 i1 w1 x1 y1 z1 _ < /proc/stat
sleep 1
read -r _ u2 n2 s2 i2 w2 x2 y2 z2 _ < /proc/stat
total=$(( (u2+n2+s2+i2+w2+x2+y2+z2) - (u1+n1+s1+i1+w1+x1+y1+z1) ))
idle=$(( (i2+w2) - (i1+w1) ))
cpu=$(( total > 0 ? 100 * (total - idle) / total : 0 ))

temp=$(awk '{printf "%.1f", $1/1000}' /sys/class/thermal/thermal_zone0/temp)
read -r mem_total mem_disp < <(awk '/^MemTotal/{t=$2} /^MemAvailable/{a=$2} END{print int(t/1024), int(a/1024)}' /proc/meminfo)
ram=$(( 100 * (mem_total - mem_disp) / mem_total ))
load=$(cut -d' ' -f1 /proc/loadavg)
uptime_s=$(cut -d. -f1 /proc/uptime)
sd_uso=$(df --output=pcent / | tail -1 | tr -dc '0-9')

if mountpoint -q /srv/servidor; then
  hdd_montado=true
  hdd_uso=$(df --output=pcent /srv/servidor | tail -1 | tr -dc '0-9')
  hdd_libre=$(df -BG --output=avail /srv/servidor | tail -1 | tr -dc '0-9')
else
  hdd_montado=false; hdd_uso=null; hdd_libre=null
fi

svc() { systemctl is-active --quiet "$1" 2>/dev/null && echo true || echo false; }

printf '{"cpu":%s,"temp":%s,"ram":%s,"ram_total_mb":%s,"ram_disp_mb":%s,"load":%s,"uptime":%s,"sd_uso":%s,"hdd_montado":%s,"hdd_uso":%s,"hdd_libre_gb":%s,"mosquitto":%s,"nodered":%s,"samba":%s}\n' \
  "$cpu" "$temp" "$ram" "$mem_total" "$mem_disp" "$load" "$uptime_s" "$sd_uso" \
  "$hdd_montado" "$hdd_uso" "$hdd_libre" "$(svc mosquitto)" "$(svc nodered)" "$(svc smbd)"
